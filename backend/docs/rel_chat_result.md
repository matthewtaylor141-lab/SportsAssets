- Branch: `claude/rel-chat` (origin), worktree `/tmp/claude-0/rel_chat`, based on `eef233b935f3f70b7e79d38a83b04df7555206af`.
- Code sha (everything tested below): `3504b1a`. This file is committed into the branch at `backend/docs/rel_chat_result.md` in the commit after `3504b1a`. That commit changes no code.
- Hard rules: no paper ledger, session or decision writer was changed (`bettor_paper_ledger.py`, `bettor_paper_session.py` and `paper_*.py` writers are untouched; `git diff eef233b --stat` lists only the files below).
