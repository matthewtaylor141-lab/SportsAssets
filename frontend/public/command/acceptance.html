— Delivery states are cumulative and distinct: BUILT (code exists) → TESTED (its tests pass) → GATED (an exact-SHA release gate accepted it) → DEPLOYED (that SHA runs in production) → PRODUCTION-READBACK (production was read back after the deploy) → FORWARD-VALIDATED (a forward sample proved it). A capability is LIVE only when its STATUS says LIVE; nothing on this page grants or implies capital authority.
