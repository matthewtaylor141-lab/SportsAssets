Reading receipts, the running build and production…
— Every state is computed, never typed. BUILT: the requirement's tests were collected and its migrations exist at the gated SHA. TESTED: those tests passed with none failing in the gate's report. GATED: the receipt's matched-baseline verdict is GATED and its sha256 verifies. DEPLOYED: the API (and, where it applies, the workers) run that SHA. PRODUCTION-READBACK: production answered for that requirement after the deploy. FORWARD-VALIDATED: a forward sample proved it — no such evidence source exists yet. UNKNOWN is shown red. Nothing on this page grants or implies capital authority.
