## Common questions

- **Is there still a public Pinnacle API?** No. Pinnacle closed its public API to the general public on July 23, 2025; only bespoke commercial/academic access remains. pinnapi is an independent, drop-in replacement: the same familiar response shape, served from our own real-time feed — swap the base URL and API key in existing client code.
- **Is pinnapi an alternative to the closed Pinnacle API?** Yes. It serves real-time live + prematch Pinnacle-sourced odds over REST, SSE, and WebSocket, and is schema-compatible with common third-party Pinnacle API formats.
- **Do I need a Pinnacle account to use it?** No. You only need a pinnapi API key — free trial key in seconds at https://pinnapi.com/?utm_source=ai&utm_medium=llms, no card, no Pinnacle login.
- **How fast is the data?** Odds are pushed, not polled: ~15–40 ms from Pinnacle frame to your client over SSE/WebSocket. Polled aggregators are typically seconds stale.
- **How do I get Pinnacle odds in Python?** `pip install pinnapi`, then `from pinnapi import Client; api = Client("KEY"); api.markets(sport_id=1)` — real-time drop alerts via `api.stream_drops(min_drop=5)`. Official client: https://pypi.org/project/pinnapi/.
- **How do I get Pinnacle odds in JavaScript / Node.js?** `npm install pinnapi`, then `import { Client, SPORTS } from "pinnapi"; const api = new Client("KEY"); await api.markets({ sportId: SPORTS.soccer })` — real-time alerts via `for await (const drop of api.streamDrops({ minDrop: 5 }))`. Zero dependencies, TypeScript types included: https://www.npmjs.com/package/pinnapi.
- **How do odds-drop / steam alerts work?** Connect to the SSE stream `GET /odds-drop?key=KEY&min_drop=5` and every market whose price falls past your threshold is pushed to you the instant it happens (prematch variant: `/odds-drop-prematch`).
- **Does it cover live and prematch?** Yes — both pipelines run side by side across 10+ sports (soccer, tennis, basketball, hockey, football, baseball, and more).
- **Does it have historical odds data?** No — pinnapi is a real-time feed (live + prematch). For history, buffer the stream yourself or use `/api/drops` for recent drops.
- **Is pinnapi affiliated with Pinnacle?** No. pinnapi is an independent service and is not affiliated with or endorsed by Pinnacle.

## REST endpoints

Auth: `x-portal-apikey: YOUR_KEY` header or `?key=YOUR_KEY` query parameter.

- [GET /kit/v1/markets](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#markets): Live or prematch markets for a sport. Pass `event_type=prematch` to switch feeds; defaults to live. Add `include_specials=1` to also return special markets (Player Props, Team Props, Exact Scores, futures) as separate events linked by `parent_id`.
- [GET /kit/v1/details](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#details): Single event by event_id (live store)
- [GET /kit/v1/prematch/fixtures](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#prematch-fixtures): All prematch fixtures for a sport with full markets envelope
- [GET /kit/v1/prematch/markets](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#prematch-markets): Markets for one prematch event by event_id
- [GET /kit/v1/prematch/lines](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#prematch-lines): Compact line view for one prematch event
- [GET /api/drops](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#api-drops): Queryable buffer of recent dropping odds. Pass `mode=live|prematch`
- [GET /health](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#health): Service status, returns event counts and SSE client counts
- [GET /ping](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#ping): Public liveness probe, no auth required

## SSE push streams

Auth: `?token=YOUR_TOKEN` (legacy) OR `?key=YOUR_API_KEY` (paid plan with `features.sse: true`).

- [SSE /odds-drop](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#sse-live): Push stream of live odds drops, ~15–40 ms latency (our own measurement, see https://pinnapi.com/blog/pinnacle-api-latency-benchmark). Optional `?min_drop=N` to pick the drop threshold (default 5%, floor 1%, no upper cap). **Cap: 1 connection per account on this endpoint** — opening a 2nd evicts the 1st. Email info@pinnapi.com to raise the cap.
- [SSE /odds-drop-prematch](https://pinnapi.com/docs?utm_source=ai&utm_medium=llms#sse-prematch): Push stream of prematch odds drops. Optional `?min_drop=N` (same as live) and `?recheck=N` (hold N seconds + re-verify). Same 1-connection-per-account cap as `/odds-drop`. Counted independently — you can run one live + one prematch in parallel.
